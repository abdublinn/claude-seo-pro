# Local SEO Signals — 2026 Reference

## Local Pack Ranking Factors

| Factor | Weight | Description |
|--------|--------|-------------|
| GBP Signals | 32% | Categories, completeness, photos, posts |
| On-Page Signals | 19% | NAP, local keywords, city in title |
| Review Signals | 16% | Count, velocity, rating, diversity |
| Link Signals | 11% | Local backlinks, authority |
| Citation Signals | 7% | NAP consistency across directories |
| Behavioral | 8% | CTR, calls, direction requests |
| Personalization | 7% | Searcher proximity, history |

## Review Benchmarks

| Metric | Minimum | Good | Excellent |
|--------|---------|------|-----------|
| Review count | 10+ | 50+ | 200+ |
| Average rating | 4.0 | 4.3+ | 4.5+ |
| Review velocity | 1/month | 1/week | 3+/week |
| Freshness | Last review <30 days | <14 days | <7 days |

**18-day rule**: Google uses a rolling 18-day window to assess review velocity changes. A sudden drop or spike is more noticeable than gradual change.

## NAP Consistency Rules

- **Name**: Exact match everywhere (including LLC/ИП designation)
- **Address**: Same format (ул. vs улица, д. vs дом)
- **Phone**: Same format (+7 vs 8, with/without hyphens)
- Schema LocalBusiness must match visible NAP on page
