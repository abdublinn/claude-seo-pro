# E-commerce SEO Plan Template

## Key Priorities
1. Product page schema (Product + Offer + AggregateRating)
2. Category page optimization (unique descriptions, not just product lists)
3. Product image optimization (WebP, alt text with product name + variant)
4. Internal linking (products ↔ guides, related products)
5. Review aggregation (pull ratings from marketplaces)

## Common E-commerce Issues
- Thin product descriptions (<150 words)
- Duplicate titles across product variations (color/size)
- Missing meta descriptions on category pages
- Cart/checkout/account pages indexed
- Faceted navigation creating duplicate content
- pa_cvet / filter parameters in index

## Content Strategy
- Buying guides ("How to choose a {product}")
- Comparison articles ("{Product A} vs {Product B}")
- Care/maintenance guides ("How to care for {product}")
- Material/technology explainers
- Customer story features

## Schema Priorities
1. Product (every product page)
2. BreadcrumbList (all pages)
3. Organization/LocalBusiness (homepage)
4. WebSite + SearchAction (homepage)
5. Article/BlogPosting (blog posts)
6. FAQPage (only if gov/health, otherwise use regular FAQ sections)
