# Generic SEO Plan Template

## Universal Priorities (all site types)

### Phase 0: Emergency (Day 1)
- Fix all 4xx/5xx errors
- Fix broken internal links
- Add missing meta descriptions to top pages
- Remove utility pages from index

### Phase 1: Foundation (Week 1-2)
- Implement correct schema for site type
- Optimize robots.txt (remove overly broad blocks)
- Clean up sitemap (remove broken/redirect/noindex URLs)
- Fix redirect chains
- Set up IndexNow
- Configure AI crawler access (robots.txt directives)

### Phase 2: Content (Week 3-6)
- Optimize title tags (unique, keyword-rich, 50-60 chars)
- Write meta descriptions for all pages
- Expand thin content pages
- Add internal links between related content
- Optimize images (WebP, alt text, compression, lazy loading)

### Phase 3: Growth (Month 2-3)
- Create new content targeting keyword gaps
- Build topical authority (pillar + cluster model)
- Implement E-E-A-T signals (author bios, credentials, sources)
- Set up llms.txt for AI search visibility
- Generate comparison/alternatives content

### Phase 4: Scale (Month 3+)
- Link building / digital PR
- Content refresh cycle (quarterly updates)
- Monitor and iterate based on Search Console data
- Advanced schema (ProductGroup, etc.)
- International expansion (if applicable)
