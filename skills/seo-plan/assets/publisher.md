# Publisher SEO Plan Template

## Key Priorities
1. Article schema on every post
2. Author pages with E-E-A-T signals
3. Topic cluster architecture (pillar + supporting articles)
4. News sitemap (if news publisher)
5. Core Web Vitals (ad-heavy pages need careful optimization)

## Content Strategy
- Pillar content (comprehensive guides, 3000+ words)
- Supporting articles (specific topics, 1000-1500 words)
- News/trending content (timely, 500-800 words)
- Evergreen updates (refresh old content quarterly)
- Interactive content (tools, calculators, quizzes)

## Technical Priorities
- AMP (optional, declining relevance)
- Pagination handled correctly
- Infinite scroll with proper URL updates
- Ad placement not blocking CWV
- RSS feed optimized
