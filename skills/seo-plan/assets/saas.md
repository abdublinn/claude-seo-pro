# SaaS SEO Plan Template

## Key Priorities
1. Feature/pricing page optimization
2. SoftwareApplication schema
3. Comparison and alternatives pages
4. Documentation SEO
5. Integration pages (one per integration partner)

## Content Strategy
- Use case pages (per industry/role)
- Integration pages (per tool)
- Comparison pages ("Us vs Competitor")
- Alternatives pages ("Alternatives to Competitor")
- How-to guides using the product
- Case studies with metrics
- Changelog/updates blog

## Technical Priorities
- Fast page load (SaaS buyers are technical)
- Clean URL structure (/features/, /pricing/, /docs/)
- API documentation indexable
- Changelog with structured data
